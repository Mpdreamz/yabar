# Yabar

Spaces, stacks and tabs for yabai, in the menu bar.

Yabar is a small macOS menu bar app for people who tile with [yabai](https://github.com/asmvik/yabai). It shows your
spaces in the menu bar, marks every stack with icons, pills or i3-style tabs beside it, and moves through stacks and
tiles with one set of keys. A launcher finds any window on any space. Layouts can be set per display: columns instead
of yabai's spiral, and the focused window always given room.

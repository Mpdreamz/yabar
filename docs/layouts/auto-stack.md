# Auto-stack

A profile's **Max tiles** caps a space: a new window that would make one tile too many goes into a stack on the tile
that had focus, or the largest tile when nothing on that space had focus. A stack counts as one tile; floating and
fullscreen windows don't count.

Only new windows move. Lowering the number, or splitting tiles by hand, rearranges nothing.

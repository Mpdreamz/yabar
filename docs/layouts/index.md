# Layouts

yabai's settings are global or per space, and forgotten when it restarts. Yabar keeps them per display and per labelled
space, and adds what yabai doesn't have.

- [Profiles](profiles.md): settings per display kind, display, or labelled space.
- [Labels](labels.md): names for spaces that survive yabai restarts.
- [Auto-stack](auto-stack.md): at most so many tiles; the rest go into stacks.
- [Columns](columns.md): columns instead of yabai's spiral.
- [Focus sizing](focus-sizing.md): the focused window always has room.

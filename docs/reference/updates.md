# Updates

Yabar checks for a new version once a day and installs it when you quit, signed with its own key on top of Apple's
notarization. **Check for Updates…** in the menu looks now. Settings → Yabar turns automatic checks and installs off.

Homebrew leaves updating to Yabar (`brew upgrade --greedy` still upgrades it).

# Stacks

yabai can stack windows in one tile, but shows only the one on top. Yabar marks every stack so you can see what is in
it and pick a window with a click.

- [Indicators](indicators.md): icons, pills or i3-style tabs, and where they go.
- [Room](room.md): how Yabar keeps them beside your windows, never over them.
- [Attention](attention.md): badges for windows that want you.
